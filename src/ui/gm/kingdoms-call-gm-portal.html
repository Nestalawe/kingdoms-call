📈 Game Statistics

Every resolved turn writes one row per realm (its orders, its situation before and after, and every battle, lair fight, capture, death and spell it was part of); every finished game writes one result row per realm. Filters apply to everything below. Exports carry the filtered rows.

🏆 Hall of Fame records

Every finished game is written to the Hall of Fame automatically when it ends. Use these to record games that finished before the board existed, or to rebuild a game's records after an engine change. Each game costs one pass over its recorded turns, so this is a button, never automatic.

# R-037: Research into a spent field turns to another

- **Decided:** 2026-09-23, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.23-2139 §42 (item 6)
- **Enforced by:** no test yet

If the field named in a Research order has nothing left (often because another scholar found its last discovery earlier that turn), the order turns to a random field that still holds something. It is refused only when every field is spent.

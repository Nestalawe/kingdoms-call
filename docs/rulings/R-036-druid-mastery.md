# R-036: Druid mastery: skill beyond the minimum strengthens beasts

- **Decided:** 2026-09-23, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.23-2139 §41 (item 3), v2026.09.23-2234 §58–59 (item 2 and Toby's rulings)
- **Enforced by:** no test yet

The old Druid creature bond (+5% a level) is retired. Instead, Creature and Monster units fight +20% for every Druid level their commander holds above the level the unit needs, up to +100%. Where the requirement is waived (a Druidic realm's Creatures, beasts tamed by Dragon Taming) the minimum is 0. A neutral guard's native command is not a waiver, and Druidic alignment never waives Monsters. Druid counts all the way to 9, items included. Psychic Blast (Druid treated as 0) and Curse (Druid halved) apply to it.

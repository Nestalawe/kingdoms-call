# R-030: Fervour: what each crown gets, and nothing stacks

- **Decided:** 2026-09-23, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.23-1752 §19, v2026.09.23-1802 §24, v2026.09.23-1956 §35 (Toby: "rulebook follows the engine")
- **Enforced by:** no test yet

An Evil host with any Monster unit, or a Druidic host with any Creature unit, fights at a flat ×1.25 every battle. An Undead commander leading any skeletal unit lifts the whole host ×1.5 (the king) or ×1.3 (a hero); a leaderless garrison gets neither. Undead realms never roll zeal. Only the strongest of these and the zeal roll counts; they never stack.

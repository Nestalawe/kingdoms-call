# R-027: Neutral heroes grow slowly and never past 5

- **Decided:** 2026-09-23, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.23-1616 §5 (item 1)
- **Enforced by:** no test yet

From turn 5, each neutral wandering hero has a 25% chance a turn to gain one skill point, never raising a skill past 5. A skill already above 5 (a released hero's) is kept.

# R-077: Guardian melee grows by grade

- **Decided:** 2026-10-08, Toby
- **Status:** Confirmed
- **Source:** PR #8, ruling 2
- **Enforced by:** [`guardian-melee`](../../tests/guardian-melee.test.js)

A guardian's melee blow is a base roll by grade (Weak 1–3, Moderate 2–5, Powerful 3–7, Legendary 4–9) plus half its Melee rounded up, as heroes' blows are.

# R-177: Rule changes reach running games

- **Decided:** 2026-11-15, a maintainer
- **Status:** Confirmed
- **Source:** Questions 69 and 73 (2026-11-15): does each game keep the ruleset it started with, and do running games get the new alignment abilities? Answer: to the first, option 2 (not the recommendation), changes reach running games, as today; to the second, option 1, every game gets each ability as it goes live.
- **Enforced by:** no test yet

There is one set of rules. A change reaches every game, running ones too, from its next turn; no game keeps the
rules it started with, and no game is created with a switch for them. ([R-094](R-094-new-units-in-running-games.md)
says how new units reach a running game.) This holds for the new alignment abilities: each reaches every game as it goes
live, and so do the changes every realm shares. Example: Lady Wren's realm is on turn 12 of a running game when a new
ability of her alignment goes live; she has it from turn 13.

**Note:** This is how the game works today. The new alignment abilities are not built yet.

The questions were: question 69, whether each game should keep the ruleset it started with (option 2: "changes reach
running games, as today"; not the recommendation, and no longer the long-term aim); question 73, running games and the
new alignment abilities (option 1: "every game gets each ability as it goes live").

In the maintainer's words: "69: (2); 73: (1) … the shared changes go into every game. No switch."

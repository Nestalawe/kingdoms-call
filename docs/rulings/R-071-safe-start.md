# R-071: Safe Start games

- **Decided:** 2026-09-29, GM option
- **Status:** To confirm
- **Source:** DEV_LOG v2026.09.29-1133 §366–369, v2026.09.29-1142 §370
- **Enforced by:** no test yet

A GM may create a game with Safe Start: no Treat or war declaration takes effect before the orders for Turn 6, for humans and bots alike, and the player portal withdraws the controls until then. It is set at creation and cannot be changed. Bots expand freely while no war can reach them.

# R-080: No single blow takes more than half a fighter's HP

- **Decided:** 2026-10-08, Toby
- **Status:** Confirmed
- **Source:** PR #8, ruling 4a
- **Enforced by:** [`hit-cap`](../../tests/hit-cap.test.js)

In personal combat no single hit takes more than half the target's maximum HP: guardian on hero, hero on guardian, and hero on hero. A Legendary guardian's own tighter cap (20%) still applies.

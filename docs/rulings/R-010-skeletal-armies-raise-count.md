# R-010: Skeletal Armies raises more with skill

- **Decided:** 2026-09-20, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG changelog v2026.09.20-0153 (Toby's five items)
- **Enforced by:** no test yet

One successful Skeletal Armies cast raises 1, 2 or 3 units at effective Necromancy 1–2, 3–4 or 5+, never more than the graves hold. A magic item cast by a non-necromancer raises one.

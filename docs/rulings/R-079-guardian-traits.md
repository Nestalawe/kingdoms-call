# R-079: A guardian never resists and is weak to the same thing

- **Decided:** 2026-10-08, a maintainer
- **Status:** Confirmed
- **Source:** PR #8, ruling 4
- **Enforced by:** [`no-guardian-resists-and-is-weak-to-the-same-thing-on-its-card-or-behind-it`](../../tests/unit/no-guardian-resists-and-is-weak-to-the-same-thing-on-its-card-or-behind-it.test.ts)

No guardian resists and is weak to the same thing; the guardian's card is the truth, and no hidden category bonus contradicts it. Where both clashing traits were on a card, the guardian got a new weakness (a maintainer approved the four new traits).

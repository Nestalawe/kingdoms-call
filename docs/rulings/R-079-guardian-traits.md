# R-079: A guardian never resists and is weak to the same thing

- **Decided:** 2026-10-08, Toby
- **Status:** Confirmed
- **Source:** PR #8, ruling 4
- **Enforced by:** [`guardian-traits`](../../tests/guardian-traits.test.js)

No guardian resists and is weak to the same thing; the guardian's card is the truth, and no hidden category bonus contradicts it. Where both clashing traits were on a card, the guardian got a new weakness (the four new traits were approved by Toby).

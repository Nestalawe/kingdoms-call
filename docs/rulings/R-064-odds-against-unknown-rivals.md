# R-064: Odds against an unknown rival show only the outcome

- **Decided:** 2026-09-27, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.27-1802 §267 (item 5)
- **Enforced by:** no test yet

Where a roll depends on a rival's skill you have not learned (pursuit, detection, breaking ranks), the report shows only whether it succeeded (✓ or ✗), with no odds band. A known rival (your own hero, a wanderer, or one spied within eight turns) gets the full working.

# R-100: Flyers fight at ×0.75 in forest and jungle

- **Decided:** 2026-10-12, Toby
- **Status:** Confirmed
- **Source:** PR #75 item 19
- **Enforced by:** [`battle-tweaks`](../../tests/unit/battle-tweaks.test.ts)

Every flyer reads the terrain table like any unit, and forest and jungle give flyers ×0.75. Illusory Terrain, which uses a unit's worst ground, takes flyers to ×0.75.

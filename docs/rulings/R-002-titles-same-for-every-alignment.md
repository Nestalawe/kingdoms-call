# R-002: Every alignment competes for every Imperial Title on the same terms

- **Decided:** 2026-09-16, Toby
- **Status:** Confirmed
- **Source:** GM portal comment "THE ALIGNMENT TITLE BOOST IS WITHDRAWN"; DEV_LOG changelog v2026.09.16-1723
- **Enforced by:** no test yet

No alignment gets a bonus to title merit. Two characters with the same deeds and skills score the same, whatever their crown.

In Toby's words: “all alignments should be the same.”

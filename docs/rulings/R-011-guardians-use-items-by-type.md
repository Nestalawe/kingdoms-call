# R-011: Guardians use hoard items by their kind only

- **Decided:** 2026-09-21, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.21-1459 §1
- **Enforced by:** no test yet

Whether a lair's guardian wields an item in its hoard depends only on the guardian's type: humanoid, undead, giant and fiend guardians use everything; dragons and fey use trinkets only; beasts, vermin, aberrations, elementals and constructs use nothing. Race and alignment locks on items do not apply to guardians.

In Toby's words: “keep type rules as-is”

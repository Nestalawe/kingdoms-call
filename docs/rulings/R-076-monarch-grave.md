# R-076: A fallen king's body stays where it was laid

- **Decided:** 2026-10-08, Toby
- **Status:** Confirmed
- **Source:** PR #8 (Batch 2026-10-08 part 2), ruling 1
- **Enforced by:** [`monarch-grave`](../../tests/monarch-grave.test.js)

A king's body is carried home at death and stays there for good, even if home is later captured.

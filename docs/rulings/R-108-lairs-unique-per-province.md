# R-108: One lair per name and one of each guardian per province

- **Decided:** 2026-10-13, Toby
- **Status:** Confirmed
- **Source:** PR #76 item 4
- **Enforced by:** [`lair-province-unique`](../../tests/lair-province-unique.test.js)

When a world is made, no province holds two lairs with the same name or two of the same guardian. Running games keep their lairs.

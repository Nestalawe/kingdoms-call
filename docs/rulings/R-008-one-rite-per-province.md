# R-008: One rite per ritual site per turn

- **Decided:** 2026-09-19, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG changelog v2026.09.19-1857; current-state summary
- **Enforced by:** no test yet

Perform Rite can be done once per province per turn, by anyone. A rite that fails before it takes place (unaffordable Wild Hunt, too few units) does not use up the site for the turn.

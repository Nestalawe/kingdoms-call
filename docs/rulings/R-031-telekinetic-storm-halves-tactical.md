# R-031: Telekinetic Storm halves the Tactical bonus

- **Decided:** 2026-09-23, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.23-1752 §19
- **Enforced by:** no test yet

In battle, Telekinetic Storm halves the enemy commander's Tactical bonus above ×1 (×2.0 becomes ×1.5); it does not cancel it.

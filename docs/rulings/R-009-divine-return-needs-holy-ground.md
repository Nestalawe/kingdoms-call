# R-009: A fallen Divine character returns only on holy ground

- **Decided:** 2026-09-20, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG current-state summary ("DIVINE RETURN NEEDS HOLY GROUND (v2026.09.20-0153, Toby)")
- **Enforced by:** no test yet

A fallen Divine character is restored only at the nearest consecrated province the realm still owns, and the return uses up that consecration. With no consecrated province, the return is lost (an ordinary Resurrect can still reach the body). A Divine king whose realm holds no consecrated ground stays dead and his heir is crowned (Toby's ruling).

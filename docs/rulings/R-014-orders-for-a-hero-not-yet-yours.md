# R-014: Orders for a hero you mean to hire, raise or charm

- **Decided:** 2026-09-21, Toby
- **Status:** Confirmed
- **Source:** DEV_LOG v2026.09.21-1221 §1–2 (Toby: "fix the hire bug you found")
- **Enforced by:** no test yet

Orders and an encounter plan written for a hero you are about to hire, raise or charm take effect only if that hire, raise or charm succeeds, and only from the phase after it lands; his remaining phases default to Defend. When two realms reach for the same wandering hero, initiative decides.

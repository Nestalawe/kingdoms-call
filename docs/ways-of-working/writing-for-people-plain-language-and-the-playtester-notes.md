# Writing for people: plain language and the playtester notes

The rules are in [CLAUDE.md](../../CLAUDE.md#plain-language-iso-24495-12023): everything people read is written to
ISO 24495-1:2023, and a pull request players can notice carries playtester notes. This file says what each asks.

## What ISO 24495-1:2023 asks

[The standard](https://www.iso.org/standard/78907.html) has four principles. Writing is:
1. **Relevant:** what readers need, nothing more.
2. **Findable:** the most important first, with clear headings.
3. **Understandable:** common words, short sentences, active voice, terms explained.
4. **Usable:** numbered steps, the next action clear.

## The playtester notes

The `## For playtesters` section holds one short, friendly paragraph per change, written for players: what's new or
fixed and how it affects their game, with no code, and numbers only where they help. It is ready for a maintainer to
paste as it is.
